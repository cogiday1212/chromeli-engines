# Chromeli engine packs

On-demand browser engine packs for Chromeli (Kameleo-style). **Binary engines only — NO source.**

Assets live on the `engines-v1` release: `catalog.json` + one `.tar.gz` per engine (Chromium + Camoufox).
The Chromeli app reads `catalog.json`, downloads the pack it needs, verifies its sha256, and installs it.
